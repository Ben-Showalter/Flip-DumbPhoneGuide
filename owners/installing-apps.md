# Installing and updating apps

These phones have no Play Store. Apps come as a single file ending in **.apk**. There are three
ways to get one onto the phone.

## Way 1: copy it from a computer with a USB cable
1. Plug the phone into the computer with a **data** cable (some cables only charge).
2. On the phone, when it asks what the USB connection is for, choose **File transfer**.
3. On the computer, open the phone, then **Internal storage** › **Download**.
4. Drag the .apk file into that folder. (You don't need an SD card; "Internal storage" is the
   phone's own memory.)
5. On the phone, open the **Files** (or **File manager**) app *(may differ)*, go to
   **Download**, highlight the .apk and press **OK**.
6. Continue at **Allow the install** below.

> A new folder you made on the phone may not show on the computer until you restart the phone.

## Way 2: download it on the phone
1. Open the link to the .apk in the phone's browser, or open it from an email attachment.
2. When the download finishes, open it (from the notification or from **Files** › **Download**).
3. Continue at **Allow the install** below.

## Way 3: install from a computer
Faster for several apps or several phones. See [Using a computer](computer-setup.md).

## Allow the install
The first time you install from a new place, Android asks for permission.
1. When the phone says it isn't allowed to install unknown apps, choose **Settings**.
2. Highlight **Allow from this source** and press **OK** so it turns on.
3. Press **Back**.
4. Highlight **Install** (press **Down** if you can't see it) and press **OK**.
5. When it says the app is installed, choose **Open** or **Done**.

## Updating
- Some apps check for updates by themselves, about once a week, and ask before downloading.
  Use Wi-Fi if you can; the app warns you when you're on mobile data.
- The first update asks you to let that app **install unknown apps**: allow it once, press
  **Back**, then choose **Install** again.
- To update by hand, install the newer .apk the same way as above. Your settings are kept.

## "App not installed" or "a different copy is installed"
This means the copy on your phone was built differently (often a test copy). To fix it:
1. If the app can **export** its data (settings, accounts), do that first. Uninstalling
   deletes the app's data.
2. Go to **Settings** › **Apps** › the app › **Uninstall**.
3. Install the new .apk again.

Other install messages are explained in [Troubleshooting](troubleshooting.md#install-problems).
