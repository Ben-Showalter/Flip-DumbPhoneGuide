# Flip phone owner's guide

This part is for **people who use a keypad flip phone**, not for programmers. It explains
how to install apps, turn on the settings they need, use the keys, and fix common problems,
with no touchscreen.

It's written for these phones, but most of it works on any keypad Android phone:
- Kyocera DuraXV Extreme (E4810 and E4811)
- Kyocera DuraXE Epic (E4610)
- Sonim XP-series phones (for example XP3800, XP5700)

## How to read this guide
- **Key names are written as they're printed on the phone**, in bold: **OK**, **Back**,
  **Clear**, **Call**, **End**, and the arrow keys **Up**, **Down**, **Left**, **Right**.
- **Steps are numbered.** Do them in order; each step is one key press or one choice.
- **Menu names may differ a little on your model.** Where a path is marked *"may differ"*, look
  for the closest-sounding item.
- You never need a computer for everyday use. A computer helps for installing apps and for a
  few settings the phone's own menus can't change.
