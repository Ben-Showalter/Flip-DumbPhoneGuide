# Keys and getting around

There's no touchscreen. You move a highlight around the screen with the arrow keys, and press
**OK** to choose what's highlighted.

## The keys

| Key | What it does |
|---|---|
| **Up / Down / Left / Right** (the navigation keys) | Move the highlight. In many apps **Left**/**Right** switch between the app's main screens |
| **OK** (centre of the navigation keys) | Choose the highlighted item |
| **Options** | Opens the app's menu. On **Kyocera** it's the **right soft key** (the key under the bottom-right corner of the screen). On **Sonim** and other phones with a **Menu** key, it's the **Menu** key, and the word "Options" shows on the **left** |
| The other soft key | Usually does nothing, so that apps work the same on every phone. Everything is in the **Options** menu |
| **Back** / **Clear** | Go back one screen. While typing, **Clear** deletes the letter before the cursor; at the start of an empty box it goes back |
| **Call** | Calls the highlighted contact. In some messaging apps it sends the message |
| **End** | Ends a call. Otherwise it goes to the home screen, and apps reopen where you left them |
| **0–9**, **\***, **#** | Typing, and shortcuts inside apps (see each app's help) |
| **Volume** keys | Volume. **Volume Up** pops up a volume bar, which can briefly take the highlight away from what you were doing |
| Camera key | Some apps use it, for example to take a picture while writing a message |
| Mic / Assistant key | Some apps use it for voice typing: hold it, speak, release |

### The first time you press Menu
On a phone with a **Menu** key, the first time you press it an app may ask:
*"Your phone has an Options key. Show the "Options" label on the left side of the screen
instead?"* Choose **Yes** so the word "Options" sits above the key you actually press. There's
no setting to change this later; the app works it out from the keys you press.

## Kyocera shortcuts
- **Hold 1** on the home screen: call voicemail.
- **Hold #** on the home screen: vibrate only. **Hold #** again: back to ring.
- **End**: home screen.

## Moving around without touch
- The highlighted item always has a coloured outline or bar. If you can't see one, press
  **Down** once.
- Lists don't wrap around: at the bottom, **Down** does nothing.
- Long messages scroll a little at a time with **Down** before the highlight moves to the next
  one.
- If a box for typing is highlighted, **Left**/**Right** move the cursor instead of changing
  screens. Press **Down** to leave the box.

## Typing
- Kyocera phones type with **T9**: press each number key once per letter and the phone guesses
  the word. The bottom of the screen shows the typing mode (T9, abc or 123).
- While you're typing, the phone's own keyboard may use the **soft keys** for its typing-mode
  menu. Apps add a **More options…** line you can reach with **Down** instead.

## Typing a date or time in a keypad picker
Some apps ask for dates and times with number keys:
- Type the digits; the picker moves to the next field by itself.
- **Left**/**Right** move between fields, **Up**/**Down** change one.
- For AM/PM, press **2** for AM and **7** for PM (the letters on those keys).
- Example: `1105` then `2026` is Nov 5, 2026; `930` then **7** is 9:30 PM.

## Push-to-talk on the right soft key
On the DuraXV, holding the **right soft key** may not register as a hold. Apps that use it for
push-to-talk then work as **tap to start, tap to stop**.
